# Project Conventions

## Schema
- The canonical schema is defined in `Phase1_MVP_Schema.md` at the workspace root. Always read it before creating or modifying lists, columns, or flows.
- **Site Columns** are the single source of truth for shared metadata. Never create list-level duplicates of site columns.
- Internal names and display names must be kept aligned. Do not use prefixed internal names with un-prefixed display names.
- **Status** on both Projects and Tasks is a user-set Choice column — never derive status from dates.
- **Next Update** on Tasks represents when the assignee commits to providing an update, not when they plan to work.

## UID Format
- Every list item gets a UID auto-generated by Flow.
- Format: `PREFIX-####` (zero-padded to 4 digits based on the list item ID).
- Prefixes: `TEAM`, `PROJ`, `TASK`, `UPDT`, `RQST`, `CONN`.

## Naming
- List names: Teams, Projects, Tasks, Updates, Requests, Connections.
- Column names: use plain, concise names. No `TwFw` prefix on columns or lists.
- Keep names aligned with the schema doc — do not invent new column names without updating the schema.

## Lists & Site URL
- All lists live on: `https://mympc.sharepoint.com/sites/mplxcontrols/`
- When connecting via PnP: `Connect-PnPOnline -Url "https://mympc.sharepoint.com/sites/mplxcontrols/" -UseWebLogin`
